## 2026-08-27 16:42 — витрина: хиро магазина с именем, лого и trust-строкой

### Added
- **Хиро-блок витрины: аватар, имя, trust-строка.** Вместо прежней строки
  `@username` шапка показывает логотип (или букву имени), показное название
  магазина и строку вида «★ 4.9 · 12 продаж». Рейтинг — средний по отзывам
  на товары магазина, продажи — оплаченные заказы (`paid/fulfilled/delivered`);
  без продаж строки нет вовсе, без отзывов из неё выпадает рейтинг.
- **Логотип магазина загружает продавец**, как фото товара: лимит 5 МБ,
  тип по содержимому, выдача по токену с immutable-кэшем
  (`shop_logos`, миграция `n9d0e1f2a3b4`; `GET /api/shop-logos/{token}`).
  Повторная загрузка удаляет старую строку, поэтому адрес всегда новый —
  заменённая картинка не может зависнуть в кэше.
- **Показное имя магазина** (`seller_bots.shop_name`, та же миграция):
  `PUT /api/seller/bots/{id}/shop-name`. Пустая строка после trim — 422,
  сбросить на дефолт клиент должен явным null — случайной очисткой поля
  магазин не остаётся безымянным.
- При подключении бота имя берётся из Telegram (`getMe().first_name`,
  до 64 символов). Реконнект заполняет его только если поле пустое:
  своё название продавца перезаписать молча нельзя.

### Changed
- Кабинет: клик по аватару магазина открывает панель «Шапка витрины» —
  превью, загрузка/замена/удаление лого (уезжает сразу после выбора файла),
  название сохраняется кнопкой.
- «Время ответа» из макета не делаем: данных для него в системе нет.

## 2026-08-27 14:37 — магазин создаётся до бота, бот — кнопкой без BotFather

### Added
- **`/newshop` в hub-боте: онбординг от названия магазина, а не от токена.**
  Название сохраняется черновиком (`app/services/shop_draft.py`), в ответ
  уходит кнопка `KeyboardButtonRequestManagedBot` — Telegram сам показывает
  диалог создания бота и сам проверяет занятость адреса. Токен забирается
  через `getManagedBotToken` и шифруется тем же путём, что при ручном вводе.
  BotFather и копипаст токена из сценария уходят совсем.
  Прогнано живьём: «кофейня у жоры» → `@kofeynya_u_zhory_bot`, бот отвечает
  на `/start`, магазин подключился.
- **Черновик магазина** — строка `seller_bots` с пустым токеном
  (миграция `n9f0a1b2c3d4`, плюс `title` как название магазина). Отдельной
  сущности нет намеренно: `bot_id` появляется сразу, поэтому каталог, витрина
  и вся изоляция по `bot_id` работают без единой правки. Покупателям черновик
  не отдаётся, вебхуков у него нет, включить его кнопкой нельзя.
- **Восстановление магазина одной кнопкой**, если продавец перевыпустил токен
  в @BotFather (созданный бот виден у него там — проверено). `bot_health`
  ловил 401 и раньше, но чинить звал руками; теперь пуш приходит с кнопкой
  «🔄 Восстановить магазин», она же лежит в карточке в `/mybots`.
  `replaceManagedBotToken` выдаёт новый токен без участия человека
  (`app/services/bot_recovery.py`). Молча не перевыпускаем намеренно: новый
  токен обнуляет тот, что продавец только что получил в @BotFather, — об этом
  сказано прямо в тексте, а нажимает он сам.
- `seller_bots.is_managed` (миграция `o0a1b2c3d4e5`): отличить бота,
  созданного нашей кнопкой, от подключённого вручную. Из токена и юзернейма
  это не выводится, а `replaceManagedBotToken` работает только с первым.
  Неуправляемому боту кнопка не показывается — обещать починку, которой нет,
  хуже честного «сходи за токеном».
- `docs/MANAGED-BOT-TEST.md` — сценарий прогона, что подтвердилось живьём и
  что осталось невыясненным.

### Changed
- Вебхук hub-бота ставится с явным `allowed_updates`
  (`app/bots/hub.py:HUB_ALLOWED_UPDATES`): `managed_bot` в дефолтную выдачу
  Telegram не входит, без списка апдейт просто не приходил бы.
- `/newshop` спрашивает `getMe` до вопроса про название. Кнопка работает
  только при поднятом `can_manage_bots` — флаг включается вручную в мини-аппе
  @BotFather («Bot Management Mode»), в чат-меню настроек его нет. Пока он
  снят, бот объясняет как включить и зовёт подключить токеном по-старому,
  вместо кнопки, которая ответит «this bot doesn't support managing bots».
- Карточка магазина с отозванным токеном больше не пишет «работает».
