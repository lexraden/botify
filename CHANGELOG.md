# Changelog

## 2026-08-22 (7)

### Added
- Фото товара загружается прямо с устройства: в форме товара вместо поля «ссылка» — выбор файла с превью, заменой и удалением; картинка необязательна. Файлы лежат в БД (`product_images`, миграция `b3c2d1e0f9a8`), раздаются публично через `/api/images/{id}` с nosniff и вечным кэшем.
- Загрузка проверяет содержимое по магическим байтам (JPEG/PNG/WebP/GIF, ≤5 МБ): присланный клиентом content-type и имя файла не учитываются. Фото принадлежит магазину (bot_id), загрузка — только владельцу. Пересобран `webapp/dist`.

### Changed
- Блок фото в форме товара: без картинки кнопка «Выбрать фото» во всю ширину формы; с картинкой — превью слева со спиннером (пока файл грузится и пока картинка не отрисовалась), «Заменить» и «Убрать» рядом справа; под заголовком подсказка «квадратный PNG с прозрачным фоном». Пересобран `webapp/dist`.

### Added
- Карточка товара на витрине: клик по карточке открывает страницу с большим квадратным фото, описанием, остатком, добавлением в корзину и кнопкой «← В каталог».
- У продавца во вкладке «Товары» видна миниатюра фото каждого товара (или эмодзи типа). Витрина: 2 товара в ряд, квадратные фото в карточках. Пересобран `webapp/dist`.

## 2026-08-22 (6)

### Fixed
- После нажатия «Я не робот 🤖» верификационная reply-клавиатура убирается из чата (сначала короткое «✅ Проверка пройдена» с ReplyKeyboardRemove, затем то же приветствие, что и на /start).
- Поле склада в форме товара показывается только у физических товаров и называется «Кол-во на складе»; у digital/услуг сток не выставляется.

### Changed
- Из кабинета в вебаппе убрана вкладка «Каналы» — подключение и настройка каналов живут в Telegram (/settings бота). API каналов на бэкенде остался без изменений. Пересобран `webapp/dist`.

## 2026-08-22 (5)

### Added
- Склад: у товара появился остаток (`stock`, миграция `f7a8b9c0d1e2`; пусто — без учёта штук). Поле в форме товара в кабинете, на витрине «Нет в наличии» при нуле, в корзину нельзя положить больше остатка, чекаут с превышением отклоняется сервером.
- Списание стока — в момент оплаты внутри идемпотентной секции вебхука: ретрай вебхука не спишет дважды, условный атомарный UPDATE не даст стоку уйти в минус при двух заказах на последнюю штуку. Неоплаченный/отменённый заказ сток не трогает. Пересобран `webapp/dist`.

## 2026-08-22 (4)

### Changed
- Верификация вступившего в канал переделана с inline-кнопки на reply-клавиатуру: внизу чата появляется постоянная кнопка «Я не робот 🤖», нажатие присылает обычное сообщение (без callback), и бот отвечает тем же приветствием из настроек бота, что и на /start (единая точка `send_welcome`). Приветствие канала (`greeting_text`) этим потоком больше не используется.

## 2026-08-22 (3)

### Added
- Верификация вступившего в канал: после авто-принятия заявки бот присылает не приветствие сразу, а кнопку «✅ Я не робот» — нажатие подтверждает telegram_id покупателя, и только потом уходит приветствие канала (правкой того же сообщения — кнопка исчезает).
- Уведомление о подключении канала приходит продавцу и в его собственный бот, а не только в hub-бот. Если у бота не отмечено право «Приглашать пользователей», продавцу приходит подсказка это исправить.
- Отключение канала продавцом: в /settings бота (кнопка «🗑 Отключить канал» с подтверждением) и в кабинете — новая вкладка «Каналы» (`GET/DELETE /api/seller/bots/{id}/channels`) с удалением в два тапа. Пересобран `webapp/dist`.
- Защита от повторной доставки апдейтов Telegram: вебхуки hub- и seller-ботов отбрасывают уже обработанные update_id (LRU-кэш в памяти процесса).

### Changed
- Заявки на вступление теперь обрабатываются только для каналов этого же магазина (поиск канала по паре bot_id + chat_id) — чужой канал недостижим из вебхука другого бота.

## 2026-08-22 (2)

### Added
- Настройки seller-бота: `/settings` в самом боте и кнопка «⚙️ Настройки бота» на карточке магазина в хаб-боте (диплинк `t.me/<bot>?start=settings`). Меню открывается только владельцу. Доступно: приветствие покупателю на /start (своё с HTML или стандартное), кнопка открытия витрины (вкл/выкл + свой текст), каналы приёма заявок (авто-приём вкл/выкл, приветствие вступившему, инструкция по подключению).
- Всё изолировано по bot_id: настройки и каналы одного бота недоступны из контекста другого, даже у одного продавца.
- Миграция `e1a2b3c4d5e6`: поля `welcome_text`, `show_catalog_button`, `catalog_button_text` у `seller_bots`.

## 2026-08-22

### Added
- Управление магазином из приложения: отключение/включение и удаление прямо на карточках кабинета (`POST /api/seller/bots/{id}/disable`, `POST /api/seller/bots/{id}/enable`, `DELETE /api/seller/bots/{id}`). Каждое действие дублируется сообщением в hub-бот.
- Inline-кнопка «🏪 Открыть магазин» в сообщении о подключении бота — ведёт в кабинет этого магазина.

### Changed
- Вебапп: страница магазина называется «Магазин» (было «Кабинет»), кнопка перехода к списку магазинов — «Кабинет» (было «Магазины»). Пересобран `webapp/dist`.
