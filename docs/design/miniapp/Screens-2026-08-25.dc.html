Статистика и кошелёк

3 рекомендации — что добавить следующим

По убыванию пользы для комфорта маркетплейса; все три не требуют менять платёжный слой.

1. ⭐ Отзывы и рейтинг товара

Доверие — главная валюта анонимного маркета: покупатель не знает продавца, и единственный его инструмент — мнение предыдущих покупателей. После доставки бот спрашивает оценку (1–5 + короткий текст), средний рейтинг показывается звёздами на карточке витрины и странице товара. Отзыв можно оставить только за свой доставленный заказ — накрутка исключена архитектурно.

среднее усилие: модель + эндпоинт + UI

2. 🔍 Поиск и категории в каталоге

Витрина — плоская сетка: после ~15 товаров покупатель листает всё подряд. Строка поиска по названию (фильтрация на клиенте, без бэкенда) и простые категории/теги у товара с фильтром сверху сетки.

малое усилие: сначала поиск, категории позже

3. 🔁 «Повторить заказ» одним тапом

В «Моих покупках» кнопка «Повторить»: тот же состав падает в корзину, цены и сток подставляются свежие. Половина повторных покупок — это «то же самое, что в прошлый раз», а сейчас для этого нужно заново найти каждый товар.

малое усилие: только фронт + готовый API корзины

Идеи второго эшелона: счётчик непрочитанного чата на вкладке «Заказы» (покупатель написал — продавцу нужен сигнал, не заходя в кабинет), бейдж активных заказов на иконке профиля, избранное, промокоды. Из уже записанного в docs/REVIEW.md ждут: детекция отозванного токена бота, напоминания по зависшим manual-заказам, бэкапы Railway.
