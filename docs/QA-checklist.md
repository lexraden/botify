# QA-checklist — ручной прогон перед первыми пользователями

Сценарий на два маршрута плюс блок «сломать нарочно». Держать открытым рядом с
Telegram. Отмечать `[x]` прошло / `[!]` сломалось, рядом одной строкой — что
именно.

Известные дыры перечислены в `docs/MVP-GAPS.md` — если упрёшься в одну из них,
это не новость, отмечай и иди дальше.

**Что нужно:** два Telegram-аккаунта (продавец и покупатель), тестовый бот от
@BotFather, @CryptoBot с парой USDT. Для безопасных денег —
`CRYPTO_PAY_NETWORK=testnet` и токен из @CryptoTestnetBot.

---

## A. Продавец

### A1. Онбординг
- [ ] `/start` в hub-боте → приветствие + кнопка «🚀 Открыть приложение»
- [ ] Экран условий: кнопка «Начать» **заблокирована** без галки
- [ ] Модалка условий открывается на весь экран, закрывается
- [ ] Вставить токен от @BotFather → «Магазин создан!» → «Далее» ведёт в магазин
- [ ] Заведомо кривой токен → понятная ошибка, а не белый экран
- [ ] Чужой уже подключённый токен → «занят другим продавцом»
- [ ] В hub-бот пришло «🎉 Бот подключён» с кнопкой «Открыть магазин»

### A2. Товары
- [ ] Создать физический товар: название, описание, цена, фото, склад = 2
- [ ] **Цена с запятой: `9,99`** → что происходит? (ожидаемо сломается)
- [ ] Цена `0` и `-5` → отказ понятным текстом
- [ ] Фото > 5 МБ → отказ, а не зависший спиннер
- [ ] Загрузить фото, заменить, убрать — превью каждый раз верное
- [ ] Создать digital-товар **со ссылкой** выдачи
- [ ] Создать digital-товар **без ссылки** — даёт ли создать (см. GAPS)
- [ ] Снять «показывать на витрине» → товар помечен «скрыт», на витрине нет
- [ ] Изменить цену → на витрине новая, в старом заказе прежняя
- [ ] Удалить товар → удаляется сразу, без подтверждения (так задумано?)
- [ ] Удалить товар, который уже покупали → деактивируется, не исчезает

### A3. Настройки бота (`/settings` в своём боте)
- [ ] `/settings` от владельца открывает меню; от постороннего — нет
- [ ] Своё приветствие → покупатель видит его на `/start`
- [ ] Сброс приветствия на стандартное
- [ ] Свой текст кнопки каталога
- [ ] Выключить кнопку каталога → см. блок D
- [ ] Приветствие с `<` в тексте → меню не ломается

### A4. Каналы
- [ ] Добавить бота админом в канал → уведомление в оба бота
- [ ] Заявка на вступление принимается автоматически
- [ ] Вступившему приходит кнопка «Я не робот 🤖», нажатие даёт приветствие
- [ ] Отключить канал из `/settings` с подтверждением

### A5. Заказы
- [ ] Оплаченный заказ виден: состав, количество, сумма, дата
- [ ] Неоплаченные и отменённые в список **не попадают**
- [ ] «Отправить покупателю»: трек / ссылка / примечание, хотя бы одно поле
- [ ] Пустая форма → отказ понятным текстом
- [ ] После отправки статус «Доставлен», кнопка пропала
- [ ] Примечание с `<` → покупатель получает уведомление (не теряется)
- [ ] Чат с покупателем: текст доходит, фото доходит
- [ ] **Смотреть на экран чата минуту** — не мигает ли поверх оверлей загрузки

### A6. Отзывы, рассылки, статистика
- [ ] Отзыв покупателя виден в «Статистике», пуш пришёл в hub-бот
- [ ] Ответ на отзыв виден покупателю на странице товара
- [ ] Повторный ответ правит прежний
- [ ] Рассылка уходит всем покупателям бота, счётчик верный
- [ ] Рассылка при отключённом магазине → понятный отказ
- [ ] Кнопка с URL в рассылке работает
- [ ] Статистика у нового магазина — нули, экран не пустой и не страшный

### A7. Деньги
- [ ] Баланс вырос на 95% суммы заказа (комиссия 5%)
- [ ] «Вывести» при балансе ниже 2 USDT → «накопленного ещё не хватает»
- [ ] «Вывести» без нажатого /start у @CryptoBot → шаг «Открыть @CryptoBot»,
      возврат в приложение повторяет вывод сам
- [ ] Успешный вывод → деньги в @CryptoBot, уведомление в hub-бот
- [ ] Нажать «Вывести» дважды подряд быстро → пачка не ломается
- [ ] Суммы везде с двумя знаками, не «95.000000»

### A8. Магазины
- [ ] Отключить магазин → бот молчит, данные на месте
- [ ] Включить обратно → бот отвечает
- [ ] Добавить второй магазин → появился экран выбора, данные не смешались
- [ ] Удалить магазин без заказов → удаляется; с заказами → только отключается

## B. Покупатель

### B1. Вход и витрина
- [ ] `/start` у бота магазина → приветствие + кнопка каталога
- [ ] Витрина: шапка, товары, цены, рейтинг у оценённых
- [ ] Поиск фильтрует по названию и описанию, ✕ сбрасывает
- [ ] «Нет в наличии» при нулевом остатке, кнопка заблокирована
- [ ] Пустой магазин → внятное пустое состояние
- [ ] **Reload Page в меню Telegram** → остаёшься в магазине, не в онбординге

### B2. Товар и корзина
- [ ] Карточка: большое фото, описание, остаток, отзывы
- [ ] Панель покупки прижата к низу и видна при любом скролле
- [ ] Добавить в корзину, менять количество степпером
- [ ] Больше остатка положить нельзя
- [ ] Закрыть и открыть приложение → корзина на месте
- [ ] Товар удалили из каталога, пока он в корзине → пропал из корзины

### B3. Оплата
- [ ] Чекаут: состав, сумма, комментарий
- [ ] «PAY» → открывается @CryptoBot со счётом
- [ ] Оплатить → пуш «✅ Заказ оплачен» со списком
- [ ] Digital-товар: ссылка пришла сразу, статус «Доставлен»
- [ ] Физический: «продавец готовит заказ», статус «Оплачен»
- [ ] **Не платить, вернуться в «Мои покупки»** → есть «Оплатить» и «Отменить»
- [ ] «Оплатить» даёт свежую рабочую ссылку
- [ ] «Отменить» → статус «Отменён», у продавца заказ не появился

### B4. После покупки
- [ ] «Мои покупки»: статусы, состав, итого
- [ ] Статус меняется сам, без перезахода
- [ ] **Смотреть на список минуту** — не мигает ли оверлей загрузки
- [ ] Трек-номер от продавца пришёл в бот
- [ ] Написать продавцу текстом в ЛС бота → продавец видит в кабинете
- [ ] Отправить фото → дошло
- [ ] Два заказа сразу: реплай на сообщение бота адресует **тот** заказ
- [ ] Оценить покупку: звёзды + текст, оценка видна на странице товара
- [ ] Изменить свой отзыв, удалить свой отзыв
- [ ] Проверить, каким именем подписан отзыв (см. GAPS п. 10)

### B5. Профиль
- [ ] Тема 🌙/☀️ переключается и запоминается
- [ ] Язык RU/EN переводит весь Mini App на лету
- [ ] «Мои покупки» открываются внутри профиля
- [ ] **«Поддержка»** — куда ведёт (см. GAPS п. 8)

---

## C. Изоляция магазинов

- [ ] Два магазина одного продавца: каталоги, заказы, покупатели, статистика
      и касса не пересекаются
- [ ] Открыть витрину магазина A и подставить `bot_id` магазина B → отказ
- [ ] Покупатель магазина A не видит заказы магазина B

---

## D. Сломать нарочно

То, что обычным прогоном не поймается. Здесь ожидаются проблемы — задача
подтвердить, что они те самые, а не хуже.

- [ ] **Отменить заказ, потом оплатить старую ссылку** из чата @CryptoBot.
      Ожидание по коду: деньги спишутся, не произойдёт ничего (GAPS 1б)
- [ ] **Нажать «Оплатить» дважды**, оплатить обе ссылки (GAPS 1в)
- [ ] **Заблокировать бота, получить рассылку, разблокировать**, открыть
      Mini App. Ожидание: 403 `banned` навсегда (GAPS 7)
- [ ] **Отключить магазин**, пока у покупателя есть оплаченный заказ →
      покупатель видит `shop not found` (GAPS 12)
- [ ] **Выключить кнопку каталога** и нажать `/start` → входа нет (GAPS 13)
- [ ] **Последняя штука с двух аккаунтов**: оба оформляют, оба платят →
      второй платёж принят, товара нет, никто не уведомлён (GAPS 3)
- [ ] **Написать в чат через 72 часа** после «Доставлен» → чат закрыт (GAPS 11)
- [ ] **Товар с `<` в названии** → купить, получить уведомление об оплате
- [ ] **Digital без ссылки выдачи** → купить, что придёт покупателю
- [ ] Оформить заказ и подождать час → инвойс протух, «Оплатить» даёт новый
